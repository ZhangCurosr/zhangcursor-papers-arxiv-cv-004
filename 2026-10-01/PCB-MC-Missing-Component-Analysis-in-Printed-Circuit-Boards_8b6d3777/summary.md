# 论文速读：PCB-MC-Missing-Component-Analysis-in-Printed-Circuit-Boards

## 一句话总结
本文构建了PCB-MC数据集，系统评估了监督式目标检测与无监督异常检测在印刷电路板缺失元件定位任务上的性能，揭示了当前模型在推断“结构缺席”时存在极高假阴性率，且无监督方法因缺乏空间对齐参考而完全失效，证明该任务仍是开放挑战。

## 研究问题与动机
1. **核心问题**：如何在PCB上准确定位“预期安装但实际未出现”的元件，而非传统意义上的可见目标检测。
2. **现有基准缺失**：RF100、FPIC、DeepPCB等公开数据集主要关注元件识别或表面可见缺陷，缺乏针对“缺失位置”的细粒度足迹级标注，无法支撑缺席检测任务。
3. **无监督方法失效**：工业主流异常检测假设训练/测试样本结构对齐且异常表现为局部外观偏离，而PCB布局多样且缺失元件往往不产生强烈局部异常，导致方法完全失效。
4. **监督检测器局限**：现有YOLO/DETR系列依赖可见外观特征，对裸露焊盘、丝印轮廓等微弱结构线索利用不足，在未见板型上漏检率极高。

## 核心贡献（创新点）
1. **提出PCB-MC数据集**：基于RF100构建首个面向缺失元件检测的基准，包含197种板型、615张图像、31个类别及9,435个缺失实例的足迹级标注。与已有工作相比，首次将“结构性缺席”定义为独立检测任务，并提供统一评估协议。
2. **设计板型感知交叉验证协议**：按唯一PCB设计类型划分训练/测试集的所有图像块，严格阻断布局信息从训练集向测试集泄露。与随机图像切分相比，真实模拟了工业场景面对全新设计板的泛化测试条件。
3. **揭示缺席检测的核心瓶颈**：通过混淆矩阵与失败案例分析证明，当前检测器的主要失败模式并非类间误判，而是候选区域生成阶段的定位缺失；分类环节的判别相对可行。与以往聚焦小目标或表面缺陷提升的工作不同，本文从“结构推理”视角重新划定任务难度边界。
4. **提出两阶段解耦流水线**：Stage 1用YOLOv11低阈值生成全图候选框，Stage 2用ResNet-18结合Focal Loss对候选区域进行缺席/存在分类。与端到端单阶段检测器相比，显式解耦定位与验证，显著降低漏检率（FNR从0.87降至0.75）。

## 方法详解
- **数据集与任务定义**：PCB-MC基于RF100扩展，修正边界框、统一标签、合并子类，共31类（23类存在元件+8类缺失元件）。定义三任务：Task A（全量31类）、Task M（仅缺失8类）、Task C（仅存在23类）。
- **评估协议**：采用板型感知的5折交叉验证（每折70%板型训练、30%验证），同板型图像的所有patch归属同一折；推理分辨率统一设为1024×1024以保留焊盘与丝印细节；评估指标为主指标mAP@0.5，辅以F1-score与假阴性率（FNR）。
- **监督检测基线**：评估YOLOv8/v11/26、RT-DETR、D-FINE五种架构，部分结合SAHI切片推理；均使用COCO预训练权重初始化，AdamW优化，300 epoch，初始学习率1e-4余弦调度；数据增强含翻转、旋转、亮度/对比度调整及Mosaic。
- **两阶段流水线设计**：Stage 1：YOLOv11以conf=0.05低阈值生成约240个候选框（覆盖全图潜在区域）；Stage 2：提取候选区域patch并放大1.4倍以捕获周围焊盘/丝印上下文，送入ResNet-18进行分类，采用Focal Loss（α=0.75, γ=2.0）缓解2:1的正负样本比例，高置信度缺失预测经NMS后输出。
- **无监督异常检测基线**：使用Anomalib实现PatchCore、PaDiM、DRAEM、Reverse Distillation，均在含完整元件的图像上训练；测试时通过0.995分位数阈值化生成分割掩码，经连通域提取与NMS（IoU=0.3）转为边界框。

## 实验与结果
- **数据集规模**：615张图像，31个类别，117,091个存在实例与9,435个缺失实例，197种独立板型，平均3.12±1.02样本/板型。
- **Task M（缺失检测）最强结果**：两阶段方法取得最佳性能，mAP@0.5 = 0.15±0.05，F1 = 0.13±0.04，**FNR = 0.75±0.07**；单阶段检测器中YOLOv11最优，mAP = 0.09±0.03，FNR = 0.87±0.03；SAHI切片提升F1但FNR仍高达0.90。
- **无监督方法完全失效**：PatchCore、PaDiM、DRAEM、Reverse Distillation在Task M上mAP与F1均为0.00，FNR = 1.00。
- **Task C（仅存在元件）结果**：YOLOv11表现最强，mAP = 0.42±0.0
