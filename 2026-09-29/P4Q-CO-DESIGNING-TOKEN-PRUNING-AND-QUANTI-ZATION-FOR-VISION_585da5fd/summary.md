# 论文速读：P4Q: CO-DESIGNING TOKEN PRUNING AND QUANTIZATION FOR VISION-LANGUAGE MODEL ACCELERATION

## 一句话总结
P4Q是一个针对视觉语言模型（VLM）的联合压缩框架，通过**量化感知的视觉token选择**与**剪枝感知的量化校准**，协同优化视觉token剪枝与低比特量化，在保持精度的同时显著提升推理效率。

## 研究问题与动机
- **低比特扰动破坏token选择稳定性**：现有基于注意力的in-LLM剪枝方法在低比特执行时，量化误差会传递至注意力分数，导致token重要性排序发生漂移（图1b显示W4A4下排名偏移可达21.6%）。
- **校准分布与推理分布不匹配**：传统PTQ在校准阶段使用全量视觉序列，而部署时模型实际处理的是剪枝后的短序列，两者在序列长度、token支持集和激活分布上存在系统性偏差。
- **独立/顺序优化的性能瓶颈**：先剪枝后量化或先量化后剪枝均无法同时解决上述两个不匹配问题，压缩性能受限。
- **VLM特殊性的忽视**：VLM同时处理视觉和语言两种模态，两者的激活统计和量化敏感度不同，需要专门设计的联合优化策略。

## 核心贡献（创新点）
1. **量化感知预LLM选择策略**：在LLM之前对投影特征进行fake量化，基于模拟低比特扰动的特征统计进行token选择，避免依赖已受污染的解码器内部状态。与现有in-LLM注意力选择方法的本质区别在于**将选择信号提前至投影特征并显式建模量化噪声**。
2. **剪枝感知量化校准策略**：使用推理时相同的选择器和token预算构建校准序列，使量化参数的拟合过程与实际部署时的剪枝执行路径一致。与密集校准方法的本质区别在于**校准序列的结构（token支持集和长度）与推理完全对齐**。
3. **三步协同选择机制**：整合查询相关性（30%）、视觉显著性（20%）和多样性完成（50%）三个互补信号，兼顾任务语义、视觉内容和覆盖广度。与单一信号剪枝方法的本质区别在于**多信号分阶段预算分配，避免冗余累积**。
4. **端到端效率-精度平衡**：在LLaVA-NeXT-7B上实现平均2.8×加速、内存降至51.3%，同时精度损失最小化。与现有方法的本质区别在于**联合优化带来的协同增益，而非简单组合**。

## 方法详解
**1. 量化感知预LLM选择（Section 3.2）**
- **Fake量化投影特征**：对projector输出的FP16特征副本进行fake量化（模拟W4A4扰动），仅用于选择器评分，原始FP16特征送入LLM。
- **三步选择公式**：
  $$S_{\text{keep}} = \alpha \text{TopK}_{i \in S_v}(\text{CosSim}(\tilde{\mathbf{q}}_j, \tilde{\mathbf{v}}_i)) + \beta \text{TopK}_{i \in S_{v'}}(A_i^{\text{cls}}) + \gamma \text{Div}(\text{CosSim}(\tilde{\mathbf{v}}_i, \tilde{\mathbf{v}}_d))$$
  - **Query Relevance（α=0.3）**：从问题中提取名词子词嵌入$\mathbf{q}_j$，与fake量化视觉特征$\tilde{\mathbf{v}}_i$计算余弦相似度，保留Top-K相关token。
  - **Visual Saliency（β=0.2）**：在vision tower最终层CLS-to-patch注意力中，以CLS为query、剩余patch为keys，取注意力权重均值作为显著性分数。
  - **Visual Diversity（γ=0.5）**：对剩余候选token计算与当前已选集合的最大余弦相似度，选择相似度最小的token（max-min原则），迭代扩展覆盖范围。
- **特征使用分离**：fake量化特征仅用于选择决策，原始FP16特征保留用于后续推理，保证LLM输入不受量化误差污染。

**2. 剪枝感知量化校准（Section 3.3）**
- **校准序列构建**：从ScienceQA训练集固定128个样本，使用与推理完全相同的P4Q选择器和token预算（88.9%剪枝率）生成剪枝序列。
- **块级校准目标**：
  $$\theta_{\ell,\text{keep}}^* = \arg\min_{\theta_\ell} \frac{1}{B} \sum_{n=1}^{B} \frac{1}{m_n^{\text{keep}} d} \| f_{\ell,\theta_\ell}^{\text{W4A4}}(H_{\ell,n}^{\text{FP,keep}}) - f_\ell^{\text{FP}}(H_{\ell,n}^{\text{FP,keep}}) \|_F^2$$
  - $H_{\ell,n}^{\text{FP,keep}}$表示经过前面完整精度块传播后的剪枝序列输入。
  - 采用block-wise sequential calibration：每个块的FP16输出作为重建目标，优化对角通道缩放因子和权重/激活裁剪参数。
- **训练细节**：AdamW优化15个epoch，学习率$5\times10^{-3}$（变换矩阵和对角缩放）/ $5\times10^{-2}$（裁剪参数），余弦退火至$5\times10^{-6}$；原始模型参数冻结。

## 实验与结果
- **评估基准**：MMMU、VizWiz、ScienceQA-TEST、MME、GQA、MMBench-CN、POPE、SEEDBench-IMG共8个多模态理解基准。
- **基线方法**：
  - 剪枝：VisPruner (ICCV'25)、VisionZip (CVPR'25)、SpecFlow (ICML'26)
  - 量化：QuaRot (NeurIPS'24)、FlatQuant (ICML'25)
  - 联合：QUOTA (arXiv'26)
- **主模型**：LLaVA-NeXT-7B（2880 token上限）、LLaVA-1.5-7B（576 token上限）、Qwen2.5-VL-7B泛化验证。
- **关键结果**：
  - **LLaVA-NeXT-7B**：平均端到端加速**2.8×**，峰值内存降至**51.3%**，平均精度保持**95.5%**（相对FP16基线）。
  - **LLaVA-1.5-7B**：平均加速**2.49×**，内存降至**42.0%**，平均精度保持**95.4%**。
  - **泛化性**：在Qwen2.5-VL-7B上，66.7%保留率时精度保持96.8%，88.9%保留率时保持90.1%，优于仅剪枝的SpecFlow。
  - **逐阶段加速**：Prefill阶段平均加速**3.33×**（VizWiz上达4.58×）。
- **消融验证**：
  - 移除fake量化（Row 4）→ 精度下降0.3%
  - 移除剪枝感知校准（Row 3）→ 精度下降0.7%
  - 两者联合（Row 5）→ 最佳性能，验证协同必要性。

## 相关工作脉络
1. **In-LLM剪枝方法**（FastV、VisPruner等）：依赖解码器内部注意力或隐藏状态评估token重要性，对量化扰动敏感且存在空间偏差（FEATHER指出）。
2. **Pre-LLM剪枝方法**（DivPrune、CRISP、LLaVA-PruMerge）：从视觉侧特征提取选择信号，避免解码器依赖，但未考虑低比特执行下的特征扰动。
3. **VLM量化方法**（Q-VLM、MBQ、TLQ、VLM-PTQ）：针对多模态敏感性差异设计校准目标，但校准序列均为密集全量序列，与剪枝推理不匹配。
4. **联合压缩尝试**（SQAP-VLA、QAPruner、QUOTA）：尝试协调量化与剪枝，但要么调整量化器辅助剪枝（SQAP），要么离线分配token预算（QUOTA），缺乏端到端联合优化框架。
5. **本文定位**：首次在预LLM选择器中显式建模fake量化扰动，并在校准阶段严格对齐推理序列结构，实现“选择-校准”闭环协同。

## 局限性与未来方向
- **量化粒度固定**：仅验证W4A4设置，更低比特（如W3A3）或混合精度场景未探索。
- **模型架构局限性**：主要在LLaVA家族验证，虽展示Qwen2.5-VL泛化性，但对其他架构（如SD3、Flamingo）的适配性待研究。
- **校准数据依赖**：128个校准样本来自ScienceQA训练集，不同数据分布对校准效果的影响未分析。
- **计算开销**：三步选择策略涉及额外相似度计算和注意力提取，预LLM阶段延迟未详细报告。
- **扩展方向**：可探索动态token预算分配、与其他压缩技术（如知识蒸馏、结构剪枝）的结合。

## 研究启发与可借鉴点
1. **Fake量化特征用于选择器设计**：在token选择前对特征进行fake量化，模拟低比特扰动，这一技巧可迁移至其他需要选择/聚类的压缩场景。
2. **校准序列与实际执行路径严格对齐**：将校准阶段的输入结构与推理阶段完全一致（相同选择器、相同预算），消除分布偏移，适用于任何引入序列长度变化的压缩技术。
3. **多信号分阶段预算分配**：将token预算按比例分配给相关性、显著性、多样性三类互补信号，通过max-min迭代扩展覆盖，该设计思想可推广至多任务选择问题。
4. **特征使用分离策略**：fake量化特征仅用于选择决策，原始高质量特征保留用于下游计算，避免误差传播，可用于任何需要“评估-执行”分离的流水线。
5. **可结合的创新机会**：将P4Q的联合优化思想应用于更广泛的VLM压缩（如KV cache量化+剪枝）、音频-语言模型、或动态推理场景（根据输入复杂度自适应调整剪枝率）。

## 关键术语表
- **视觉token剪枝**：在视觉语言模型中移除冗余或低信息量的图像patch token，缩短序列长度以降低计算成本。
- **后训练量化（PTQ）**：在不重新训练模型的情况下，将权重和激活的数值精度降低（如W4A4表示4位权重和4位激活），减少内存和计算开销。
- **Fake量化**：在特征上模拟量化操作的误差分布，但不实际量化参数，用于评估低比特环境下的模型行为。
- **预LLM选择**：在文本语言模型之前，基于视觉侧特征或轻量交互信号提前决定保留哪些视觉token。
- **校准分布**：量化过程中用于估计缩放因子、裁剪范围等参数的激活数据分布，通常来自校准数据集的正向传播结果。
- **Top-K重要性漂移**：低比特扰动导致token重要性排序发生重新排列，使原本Top-K的token集合发生变化。
- **块级校准**：按语言模型层逐块进行量化参数优化，每块以全精度输出为目标重建低精度输出，避免误差累积。
- **效率-精度权衡**：压缩方法在推理加速/内存节省与任务性能保持之间的平衡能力。

## 可复现要素
- **数据集**：MMMU、VizWiz、ScienceQA、MME、GQA、MMBench-CN、POPE、SEEDBench-IMG均公开；校准集使用ScienceQA训练集固定128样本（随机种子42）。
- **代码/权重**：论文未明确提及代码开源状态；基线模型（LLaVA-NeXT-7B、LLaVA-1.5-7B）为公开权重。
- **关键超参**：
  - 预算分配：α=0.3（查询相关性）、β=0.2（视觉显著性）、γ=0.5（视觉多样性）
  - 剪枝率：88.9%（保留11.1% token）
  - 量化格式：W4A4（4位权重、4位激活，KV cache保持FP16）
  - 校准样本数：128
  - 训练轮数：15 epoch，AdamW优化，学习率$5\times10^{-3}$/$5\times10^{-2}$余弦退火至$5\times10^{-6}$
- **硬件环境**：NVIDIA RTX 4090 (24GB)，Python 3.10.20，PyTorch 2.6.0，CUDA 11.8。
