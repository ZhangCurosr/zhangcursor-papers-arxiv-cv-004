# 论文速读：RATE-DISTORTION-ADAPTIVE-PRIMITIVE-SELECTIONFOR-OMNIDIRECTIO

## 一句话总结
本文提出 OIC-GS，一种基于分层 HEALPix 网格的全向高斯溅射（GS）图像编解码器；通过将量化不透明度与学习熵模型的比特率耦合，实现率失真自适应的基元自动剪枝，单码流同时支持全球面、视口依赖与渐进解码，首视口仅需接收 52% 码流即可达到最终质量并以 1,270 FPS 实时渲染。

## 研究问题与动机
1. **解码延迟与 VR 需求不匹配**：学习图像编解码器（LIC）重建质量高，但需解码完整潜在表示并通过解码网络前向传播，难以满足沉浸式 VR 的实时解码要求；GS 编解码器渲染更快，但现有全向 GS 编解码器在重建质量上仍落后，且基元分配未联合考虑编码代价。
2. **ERP 投影导致极点采样失衡**：现有全向 GS 编解码器多基于等距柱状投影（ERP），极点区域采样密度过高，优化过程会将过多基元分配至极点，造成码率浪费与率失真（R-D）性能下降。
3. **两阶段优化割裂了 R-D 联合决策**：主流方法先根据重建质量确定基元位置/数量，再固定基元集优化属性，导致无法联合权衡每个基元的编码成本与失真下降，难以实现 R-D 最优的基元选择。
4. **全图重建不适配视口观看模式**：VR 用户仅查看局部视口，现有 LIC 与 GS 编解码器均需重建完整全景图后再投影视口，引入不必要的传输与解码延迟。

## 核心贡献（创新点）
1. **率失真自适应基元选择（RDPS）**：将基元的量化不透明度与熵模型估计的比特率耦合，在统一的 R-D 优化目标中自动将低收益基元的不透明度压至零，无需预设基元预算。
2. **单码流三模式解码与实时视口渲染**：同一码流支持全球面、视口依赖与渐进解码；首个视口仅需解码 52% 文件即可达到最终质量，且视口渲染速度达 1,270 FPS，与全图解码结果位精确一致。
3. **面向单张全向图像压缩的分层 HEALPix GS 表示**：直接在球面上构建层级网格，基元锚定在 predefined 格点中心，消除显式坐标编码开销，天然支持粗到细的层次化重建与分层传输。

## 方法详解
- **分层球面高斯表示**：默认 $L=7$ 层 HEALPix 等面积网格（$\ell \in \{0,\ldots,6\}$），每格点一个基元，无独立位置与协方差。每个基元携带 4-bit 量化特征 $f$ 与 2-bit 量化不透明度 $\hat{\alpha} \in \{0, 1/3, 2/3, 1\}$。
- **渲染与存在掩码**：按粗细层级顺序累加渲染（Eq. 3–6）。当 $\hat{\alpha}_i^{(\ell)} = 0$ 时基元失活，其属性回退至粗层平均值 $\bar{F}^{(\ell-1)}$，保证渲染连续性；阈值 $\tau=0.2$ 划分激活状态，中间值 $\{1/3, 2/3\}$ 作为过渡缓冲区，允许邻域与粗层渐进适应。
- **渲染条件上下文熵模型（RCC）**：特征逐层编码，上下文由三部分拼接（Eq. 7）：粗层预测值（9邻域）、父节点特征、偶奇棋盘格上下文（两_pass 调度）。ContextMLP 输出 3 分量高斯混合模型（GMM）用于算术编码（Eq. 8），第 0 层使用全局先验。
- **可微率估计与代价加权**：训练期活跃基元的特征率 $\tilde{R}_{\text{feat}}$ 通过分段线性函数 $\omega(\hat{\alpha})$ 加权（Eq. 10–11），使中间透明度状态承担部分比特成本，保证梯度可流回不透明度。
- **联合 R-D 优化**：$\mathcal{L} = D + \lambda_R(\tilde{R}_{\text{feat}} + R_{\text{mask}}) + \lambda_s E_{\text{reg}}$，沿用 overfitted coding 范式，每图独立端到端拟合特征、不透明度、ColorMLP、ContextMLP 及核宽/混合参数，基元集合由优化自动涌现。

## 实验与结果
- **数据集**：主基准 100 张 2048×1024 ERP 全景图（Flickr 来源），跨数据集验证使用 SUN360 测试集 100 张。
- **评估指标**：WS-PSNR、V-PSNR、V-SSIM、V-LPIPS；BD-rate 以 JPEG 为锚点计算。
- **基线**：GS 类（SGI、GaussianImage、GaussianImage++、LIG）与非 GS 类参考编解码器（COIN、JPEG2000、JPEG）。
- **主要结果**：OIC-GS 在所有测试码率下全面超越 GS 基线。相对 GaussianImage++ 的 WS-PSNR BD-rate 降低 49.6%；相对唯一带学习熵模型的 SGI，WS-PSNR BD-rate 降低 68.6%（V-PSNR 降 67.1%，V-SSIM 降 57.7%，V-LPIPS 降 66.3%）。SUN360 跨数据集验证保持领先优势。
- **解码性能**：首视口仅需解码 52% 码流即达最终质量（bit-exact），固定视口渲染 1,270 FPS，全球面渲染 140 FPS；tile-aligned 格式平均仅增 1.2% 文件大小。
- **消融**：移除速率感知不透明度加权（$\omega_{\text{lo}}=\omega_{\text{hi}}=1$）导致率增长 31.2%（最大退化）；移除 RCC 导致 +5.9%；特征率估计改用 STE 代替均匀噪声导致 +2.5%。

## 相关工作脉络
1. **全向图像压缩（LIC/OSLO/Viewport-based）**：传统投影方法需解码全图或固定视口链后才显示目标区域，延迟高；OIC-GS 直接从基元渲染视口，无需全图网络前向传递，且极区视口不会被拉伸为全宽条带。
2. **2D GS 图像压缩（GaussianImage 系列 / LIG）**：属性压缩由重建误差驱动，使用固定熵编码或 bit counting，基元数量受生长预算或 LOD 分配控制，无法由率梯度驱动；OIC-GS 用学习熵模型 + R-D 目标实现基元自适应剪枝。
