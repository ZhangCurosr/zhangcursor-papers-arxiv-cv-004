# 论文速读：ON-POLICY-SELF-DISTILLATION-FOR-MULTI-TURN-IMAGE-EDITING

## 一句话总结
本文提出了 MT-OPSD，一种在线策略自蒸馏框架，用于解决指令图像编辑在多轮迭代时因条件分布不匹配导致的累积误差退化问题。该方法仅需单轮训练数据，通过在模型自生成的状态上进行训练，并借助干净条件下的教师监督，显著提升了十轮长程编辑的成功率并降低了崩溃率。

## 研究问题与动机
- **多轮编辑性能急剧下降**：现有单轮训练的指令图像编辑模型在递归应用自身输出时会出现高频色噪、结构破碎和身份漂移等严重退化，且该现象在不同模型间普遍存在。
- **根本原因是训练-测试条件分布不匹配**：模型仅在干净源图像上训练，而推理时需反复对自身包含误差的输出进行条件处理，误差逐轮累积。
- **多轮标注数据稀缺且端到端优化成本过高**：优化多轮展开需跨数百个去噪步骤反向传播，计算代价不可承受。
- **现有训练无方法的局限性**：如 Emu Edit 等方法仅通过像素回退缓解局部编辑漂移，无法处理全局变换（重着色、重照明等）。

## 核心贡献（创新点）
- **揭示了多轮退化的本质原因**：首次系统归因于条件分布的训练-测试不匹配，而非模型特定缺陷。
- **提出 MT-OPSD 在线策略自蒸馏框架**：利用预训练模型自身的干净条件行为作为监督信号，将单轮编辑能力迁移至自生成状态，无需多轮标注或外部教师模型。
- **设计身份展开隔离模型误差**：通过反复执行"保持原图不变"指令生成退化状态，分离出纯粹的模型诱导误差，避免与语义变化纠缠。
- **构建 LME-Bench 基准**：包含100个十轮编辑会话（各含局部与全局操作），填补了长程多轮编辑评估的空白。

## 方法详解
- **自生成展开状态**：从干净源图像 $I^{(0)}$ 出发，用身份指令 $e_{\mathrm{id}}$（如"Make everything unchanged"）递归运行学生模型 $k$ 轮，得到 $\tilde{I}^{(k)} = G_{\theta_S}(\tilde{I}^{(k-1)}, e_{\mathrm{id}})$，此时状态差异主要反映模型误差。
- **双分支训练目标**：
  - **身份分支**（$\mathcal{L}_{\mathrm{id}}$）：以展开状态自身为目标，防止误差进一步放大，损失为速度模型与 $\epsilon - \tilde{x}_0$ 的 MSE。
  - **编辑分支**（$\mathcal{L}_{\mathrm{edit}}$）：在自生成状态 $\tilde{I}^{(k)}$ 上施加真实编辑指令，学生与冻结教师在相同噪声潜变量处的速度进行稀疏查询匹配，学生状态采用 stop-gradient。
- **自适应展开课程**：以相邻轮次输出的平均像素偏差衡量漂移，仅当漂移低于阈值并持续若干步后才增加深度，无需手动调度。
- **门控教师提升**：定期用 VLM judge 在预留验证集上评估学生检查点，满足长程成功与低崩溃率阈值时替换教师。

## 实验与结果
- **数据集**：自建 LME-Bench（100 会话×10 轮）、MSE-Bench（100 会话×5 轮）、ImgEdit（单轮基准）；训练使用 OmniEdit 的 2,000 对单轮数据。
- **基线**：原始骨干模型 + 训练无方法 Emu Edit、FreqEdit、VAE-LFA；闭源 GPT-Image-1/2、Nano Banana。
- **LME-Bench 主结果**（SR@10 / CR@10）：
  - Qwen-Image-Edit-2511：0.03 / 0.55 → **0.44 / 0.02**
  - FireRed-Image-Edit：0.15 / 0.61 → **0.52 / 0.03**
  - FLUX.2-klein-base：0.12 / 0.25 → **0.38 / 0.04**
- **MSE-Bench**：Qwen+MT-OPSD SR@5 从 0.24 提升至 0.51；FireRed 从 0.40 提升至 0.69。
- **ImgEdit**：单轮质量基本保持，小幅下降（Qwen: 4.51→4.49）。
- **超越 GPT-Image-1**：在所有报告的轮次和指标上均优于 GPT-Image-1。
- **消融**：移除身份分支导致过度编辑和单轮性能下降；移除编辑分支使 SR@10 降至 0.00；固定教师限制 SR@10 至 0.19。

## 相关工作脉络
- **MT-EditFlow**（Huang et al., 2026a）：同样归因于 exposure bias，但通过 RL+外部奖励监督解决，MT-OPSD 无需额外标注或奖励信号。
- **Emu Edit / FreqEdit / VAE-LFA**：训练无方法，依赖像素级或频率级修正，仅适用于局部编辑，不改变模型行为。
- **VINCIE**（Qu et al., 2026）：基于视频架构训练专用多轮模型，需完整编辑历史条件；MT-OPSD 在仅依赖前一轮输出的设定下仍取得更高 SR@10。
- **AnchorEdit**（Xu et al., 2026）：使用因果记忆维护多轮一致性，需额外记忆模块；MT-OPSD 无需额外组件。
- **D-OPSD / OPSD-V / DiffusionOPSD**：视觉/视频领域的在线自蒸馏方法，利用目标图像或长视频上下文作为教师条件；MT-OPSD 的创新在于将自蒸馏应用于多轮编辑中自生成的退化状态，教师条件为干净的源图像。
- **Edit-R2**（Ye et al., 2026b）：RL 风格方法关注会话级约束保持；MT-OPSD 从零开始学习条件鲁棒性。

## 局限性与未来方向
- **课程饱和深度有限**：自适应课程通常在约 4 轮时饱和，但评估在 10 轮，更深序列的鲁棒性未充分验证。
- **身份指令依赖**：需要精心设计的身份提示词，不同措辞可能影响误差隔离效果。
- **全局编辑仍具挑战**：相比局部编辑，全局变换（如风格迁移）的长期稳定性仍有提升空间。
- **训练成本增加**：需额外的身份展开步骤和异步教师评估，训练时间约为单轮训练的数倍。
- **未来方向**：扩展至更深轮数（20+ 轮）、探索无需身份指令的误差隔离方法、集成全局编辑专用修正机制。

## 研究启发与可借鉴点
- **误差隔离思想**：通过"恒等变换"引导的展开来分离模型误差与目标语义变化，可迁移至其他递归生成任务（如多轮对话生成、迭代视频编辑）。
- **稀疏查询速度匹配**：仅在少数采样步进行师生对齐，兼顾训练效率与监督质量，可推广至其他扩散/流匹配模型的蒸馏场景。
- **自适应课程自动调节**：基于漂移度量的深度推进策略无需手动调参，可应用于其他需渐进式困难增强的训练流程。
- **门控教师提升机制**：异步评估+阈值触发替换，平衡了单轮能力保持与多轮鲁棒性提升，为持续学习提供新思路。
- **LME-Bench 评估协议**：结合 SR@k（累积成功）与 CR@k（累积崩溃）的双指标设计，以及对"两连续轮退化"定义崩溃的稳健策略，值得在其他序列生成任务中复用。

## 关键术语表
- **多轮图像编辑（Multi-turn Image Editing）**：用户逐轮提供指令，每轮编辑基于上一轮输出进行的迭代式图像修改过程。
- **条件分布训练-测试不匹配（Train-Test Mismatch in Conditioning Distribution）**：模型仅在干净源图像上训练，但推理时需对其自身含误差的输出进行条件化，导致性能退化。
- **在线策略自蒸馏（On-Policy Self-Distillation, OPSD）**：学生在自身策略生成的状态下学习，由同一模型在更丰富条件下作为教师提供监督。
- **身份展开（Identity Rollout）**：反复应用"保持原图不变"指令生成退化状态，用于隔离模型诱导误差。
- **稀疏查询速度匹配（Sparse Query-based Velocity Matching）**：仅在学生去噪轨迹的少数采样步对齐师生速度，源自 DanceOPD。
- **LME-Bench**：Long Multi-turn Image Editing Bench，包含100个十轮编辑会话的基准测试，涵盖局部与全局操作。
- **自适应展开课程（Adaptive Rollout Curriculum）**：基于漂移度量自动推进展开深度的训练策略，避免早期引入过深退化。
- **门控教师提升（Gated Teacher Promotion）**：由 VLM judge 异步评估并决定是否用改进学生替换教师，保持教师稳定性与探索性之间的平衡。
