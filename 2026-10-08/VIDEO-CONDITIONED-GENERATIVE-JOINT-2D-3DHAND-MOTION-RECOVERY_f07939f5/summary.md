# 论文速读：VIDEO-CONDITIONED-GENERATIVE-JOINT-2D-3DHAND-MOTION-RECOVERY

## 一句话总结
提出 JoHan，一种直接从单目视频序列中联合生成对齐的局部 2D 与 3D 手部运动轨迹的统一生成框架，无需依赖预训练的逐帧姿态估计器；通过流匹配建模时序动态并以 2D 轨迹引导 3D 生成，再利用 2D–3D 几何对应恢复全局位姿，在 HO3D 与 HOT3D 基准上同步提升了局部精度、相机空间重建质量与运动平滑性。

## 研究问题与动机
- 现有方法多将手部重建视为确定性回归，或将生成建模建立在预训练的逐帧姿态估计之上，遮挡、运动模糊等视觉歧义会导致初始估计误差沿时间累积，破坏序列一致性。
- 2D 手部轨迹虽能提供强图像空间约束，但现有工作通常将其作为固定观测输入，缺乏对 2D 轨迹自身时序连续性与动态过程的显式建模。
- 纯 3D 生成受限于固有深度歧义，仅靠像素线索难以充分约束；而 2D 与 3D 通过投影几何天然关联，联合建模可互补 3D 的动态表达力与 2D 的视觉约束力。
- 需要一种端到端的生成式框架，直接学习视频条件分布下的 2D–3D 联合运动先验，并将局部姿态动力学与全局相机空间变换解耦，以降低对外部检测/姿态估计器的依赖。

## 核心贡献（创新点）
1. **端到端联合生成框架 JoHan**：直接从视频学习手部运动分布，无需预训练逐帧姿态估计器。与以往依赖外部姿态引导或测试时优化拟合的方法本质不同，实现了从原始帧到运动序列的零中间产物生成。
2. **2D-Guided Fusion 跨模态耦合机制**：在共享流匹配时间轴上联合生成局部 2D 与 3D 序列，使不断演化的 2D 几何预测在每一步流步骤中条件化 3D 速度场。区别于单向引导或独立训练，两分支通过重投影损失显式维持几何一致性。
3. **局部-全局解耦的相机空间恢复管线**：生成归一化局部
