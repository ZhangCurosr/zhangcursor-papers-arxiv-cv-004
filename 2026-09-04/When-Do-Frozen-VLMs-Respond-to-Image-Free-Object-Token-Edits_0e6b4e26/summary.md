# 论文速读：When-Do-Frozen-VLMs-Respond-to-Image-Free-Object-Token-Edits

## 一句话总结
本文提出了一种无需后编辑标准答案的评估协议，系统刻画了冻结 VLM 在将图像抽象为可编辑对象 token（节点）后，究竟在何种条件下能响应删除/移动/添加类反事实编辑；发现响应能力并非自然具备，必须经过显式编辑教学，且受 token 清洁度与场景密度严格制约，而原生自由文本 VQA 能力可在节点路由下保留基线的 92%–96%。

## 研究问题与动机
- **核心问题**：当图像被完全抽象为对象 token 集且原图不再输入时，冻结 VLM 在何时/何种条件下会真正响应针对这些 token 的编辑操作？
- **文本注入路径不足**：通过提示词假设（如“假设 X 消失”）会让指令与残留视觉证据冲突，无法判断模型答案究竟遵循了哪一方。
- **生成重绘路径不足**：借助生成模型重绘后再输入，会使答案绑定于生成器的幻觉与先验，并引入合成伪影作为额外误差源。
- **表征级编辑的前提不显然**：即使模型能从节点做好 VQA，删除对象后仍可能答“存在”（默认零响应），因此需构建最小可编辑测试床并量化其响应边界。

## 核心贡献（创新点）
1. **无标准答案（answer-key-free）的编辑响应评估协议**：仅利用逻辑确定编辑、安慰剂相减、前正确条件过滤与打乱证据控制，在不依赖人工重建答案的前提下量化响应度。
2. **刻画冻结 VLM 编辑响应的三大约束结构**：响应非免费（普通 VQA 训练无法自动赋予，需显式编辑教学）、受 token 清洁度与密度治理、读取能力可作为正交通道独立保留。
3. **构建最小可编辑测试床并开源全套测量资源**：仅训练 ~15M 投影器，对象 token 由冻结编码器+掩码池化生成，同步发布探针生成器、评估记录、judge 日志与代码，支持同类系统复用。
4. **验证跨数据集与跨模型主干的符号一致性**：在 iSAID、VRSBench 两个遥感数据集及 LLaVA-OV-7B、Qwen2.5-VL、Idefics3-8B 三个冻结 LM 上，清洁度排序与教学增益的符号均稳定复现。

## 方法详解
- **对象 token 构建**：冻结视觉编码器输出空间特征图 → 对候选掩码区域做平均池化得节点特征，并按比例 λ=0.5 减去图像均值特征（去全局化）→ 为每个节点附加 K=10 维傅里叶位置编码（质心、包围盒、面积），不附加类别标签；掩码即全部视觉证据，原图永不进入 VLM。
- **编辑操作定义**：`delete`（移除目标 token）、`move`（重写目标 token 的位置编码，特征保留）、`add`（复制另一真实节点的特征并改写位置，嫁接至空位，全程无生成内容）。
- **轻量训练设置**：仅训练 2 层 MLP 投影器（~15M，隐藏维度对齐 LLM），视觉编码器与 LLM 完全冻结；训练数据由标准 VQA 与程序化生成的编辑对混合，其中编辑教学对仅含逻辑答案确定的样本（存在对、位置对、添加三元组），按 `presence : position ≈ 1.5 : 1` 混合，一半类别用于教学，另一半作泛化留白。
- **无标准答案评估协议**：
  - **选择性 SEL（删除）**：$\mathrm{SEL} = \Delta P_{\mathrm{rel}} - \Delta P_{\mathrm{irrel}}$，删除目标类节点 vs 删除无关类节点的 yes 概率下降差。
  - **单调性 MON（移动）**：$\mathrm{MON} = \Delta P_{\mathrm{cross}} - |\Delta P_{\mathrm{null}}|$，跨中线移动 vs 同半区移动（安慰剂）的答向变化，分垂直/水平轴。
  - **插入选择性 $\mathrm{SEL}_{\mathrm{add}}$**：真实节点特征插入 vs 无关类插入/空位安慰剂的 yes 漂移差。
  - 所有指标均做过安慰剂相减与前正确条件过滤（仅保留编辑前 $P(\mathrm{correct}) > 0.5$ 的样本）；另设 `shuffled-evidence` 控制（整集节点置换配对）提取节点驱动分量 $\mathrm{driven} = \mathrm{normal} - \mathrm{shuffle}$。
  - 评分在第一个解码步进行两两强制选择重归一化：$P(a|Z,q) = \frac{\exp \ell_a}{\sum_{a'\in A_q}\exp \ell_{a'}}$，$\ell_a = \max_{t\in\mathcal{T}_a} z_t$，不采样、不降温。

## 实验与结果
- **数据集与基线**：iSAID（密集，374 全图，中位 ~47 节点/图）与 VRSBench（稀疏，1121 块 tile，均 ~1.8 对象/tile）。节点源设 Oracle/GT、Det+SAM（YOLO-OBB+SAM box prompt，可部署）、SAM-raw（全掩码过分割）三档；对照路由为 Patch（256-token 固定网格池化）；训练设 EA（VQA+编辑教学）与 VO（仅 VQA）。
- **核心定量结论**：
  - 编辑响应非默认：VO 在 iSAID 密集图上 SEL 仅 +0.002（Oracle）/ +0.003（Det+SAM），接近零；EA 提升至 +0.049 / +0.044，CI 分离。
  - 清洁度轴：密集 tile 上 SEL 从 SAM-raw(+0.002) 阶梯攀升至 Det+SAM(+0.408)；图像级别 Oracle−Det+SAM 差距 Δ=+0.005[−0.007, 0.018] 不显著，部署档已达理论上限。
  - 密度规律：固定编辑目标、仅增加无关上下文节点时 SEL 单调衰减，拟合幂律 $\mathrm{SEL} \propto N^{-0.67}[0.57, 0.79]$；在 ~58 节点 token 时仍维持 SEL≥0.10。
  - 添加操作：EA 训练下 L2 跨场景特征嫁接 $\mathrm{SEL}_{\mathrm{add}}$ 达 +0.122（Det+SAM）/ +0.195（Oracle），显著超零样本；未教学类保持 ≈0，呈现类局部性。
  - 读取保留与节点依赖：自由文本 VQA 在节点路由上保留 Patch 基线（iSAID .564）的 92%–96%；VRSBench 上 Det+SAM-EA 达 101%，driven 分量 +0.191[.161, .218]。若同时保留原图输入，SEL 骤降 76%–81%，driven≈0，说明读取与响应可解耦但非独立。
