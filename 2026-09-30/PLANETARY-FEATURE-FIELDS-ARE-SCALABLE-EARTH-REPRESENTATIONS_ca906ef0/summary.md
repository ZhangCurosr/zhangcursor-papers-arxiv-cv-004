# 论文速读：PLANETARY FEATURE FIELDS ARE SCALABLE EARTH REPRESENTATIONS

## 一句话总结
论文提出 Planetary Feature Fields (PFFs)，一种空间局部的显式-隐式混合神经网络场，通过跨产品共享因式分解特征体积，实现对 14 种多源地球观测产品的高保真压缩表示（约 1800×），并在像素级分割、变化检测等下游任务中保留约 90% 以上性能，同时支持高效续习新时间步和产品而不遗忘历史数据。

## 研究问题与动机
- 卫星原始观测、预计算嵌入与地图产品以独立形式存储为 PB 级数据产品，随着时间增长，存储、传输和版本管理成本线性增长，亟需紧凑的多产品联合表示。
- 现有两类替代方案各有不足：地理坐标编码器（如 SLED、SatCLIP）可提供紧凑全局隐式表示，但缺乏重建源数据所需的空间细节；预计算嵌入保留特征但随时间扩展导致存储与访问开销持续放大。
- 现有神经辐射场（NeRF 类）方法通常针对单一产品优化，跨产品共享表示时难以兼顾不同分辨率、维度与统计特性的异构数据，且续习新知识易引发灾难性遗忘。
- 地球观测数据具有各向异性：空间采样密集（数千点/轴），时间采样稀疏（每年仅个位数观测），需要非对称的容量分配机制。

## 核心贡献（创新点）
- **提出 PFFs：空间局部显式-隐式混合表示框架**，通过共享因式分解特征体积（TensoRF(VM) 或 K-Planes）联合建模多产品，相比单产品神经场在同等压缩率下重构精度提升约 20%。
- **实现高压缩率下的下游性能保留**：在 1800× 压缩比下，PFF 重建特征在 PASTIS 分割、FTW 边界检测、EuroMineNet 变化检测等任务上保留 90% 以上原始特征性能（部分任务超越原始特征）。
- **支持比特精确的持续学习**：新增时间步仅需扩展 0.19%~0.22% 参数（追加时间切片），训练时间仅为联合预训练的 2%，同时保留历史年份输出比特精确不变；新增产品仅需训练 2% 参数（新解码器），不更新共享字段。
- **端到端检索延迟降低一个数量级**：相比 Google Earth Engine API 和云存储下载管线，PFF 特征物化速度快 15.5×~17.9×，在 H100 GPU 上达到 970 万 AE 嵌入/秒。

## 方法详解
- **空间分区与局部场**：将地理域划分为边界区域（tile），每个区域独立学习局部函数，查询时路由至对应 tile 并转换到 tile 内笛卡尔坐标，缩放至 [0,1]²，避免全局坐标编码的容量瓶颈。
- **显式-隐式混合架构**：每个 PFF 由共享显式因式分解特征体素 + 产品特定轻量 MLP 解码器组成；查询 (x, t) 时，从因子中插值得到共享特征向量 h ∈ R^dh，再由 g_m(h) 映射到产品 m 的原生特征空间。
- **因式分解特征体素**：采用 TensoRF(VM) 或 K-Planes 两种因子化方式，分别用矢量-矩阵分解（线性因子 × 平面因子 × 基底向量求和）或三平面逐元素相乘（P^xy ⊙ P^xt ⊙ P^yt）近似稠密时空网格，独立设置空间与时间分辨率以匹配 EO 数据的各向异性（本文 VM 用 S=955 空间分辨率、65 分量，K-Planes 用 4 尺度 147/294/588/1176）。
- **训练与缺失数据鲁棒性**：按产品分别计算标准化 MSE（欧氏值）或余弦失真（单位嵌入）， masked 不可用目标后加权求和；粗分辨率产品通过最近邻重采样对齐到 10m 公共网格，保留源单元格与 nodata 值；使用固定容量 GPU 缓冲区 + 部分 COG 读取，避免全量加载（单区域产品栈中位内存 227.5 GB）。
- **续习新时间步**：追加时间切片（VM 扩展 v_r^t, M_r^xt, M_r^yt，增加 124K 参数；K-Planes 扩展 P^xt, P^yt，增加 141K 参数），冻结其余参数，仅在新切片上训练；因插值锚点不变，历史年份输出比特精确保持。
- **续习新产品**：冻结共享字段与已有解码器，仅训练新产品对应的 1.25M 参数解码器（约 2% 总参数），可在子集像素上训练。

## 实验与结果
- **数据集与评测基准**：PFFBench 含 100 个全球 tile（约 67 亿空间位置、16 TB 源数据），14 种 EO 产品覆盖 2017–2025（含 Sentinel-2/1、Landsat、AlphaEarth、TESSERA、DEM、Canopy、Biomass 等）；下游任务包括 PASTIS（作物分割）、SwissCrop25、FTW（田块边界/ extent）、EuroMineNet（年度矿山变化检测）、BigEarthNet-v2、So2Sat-LCZ42。
- **重构性能**：共享 PFF（VM/K-Planes）在 100 tile 上平均归一化失真比单产品 TensoRF(VM) 低约 20%；K-Planes PFF 平均得分为 91.1 vs 单产品 Solo K-Planes 88.9，AlphaEarth 得分 89.5 vs 86.9。
- **下游任务保留率**：PFF-VM 在 PASTIS 上保留 90%（AE）/90%（TE）/136%（S2）；FTW Brazil 保留 90%（AE）/90%（S2）；EuroMineNet AUPRC 保留 100%（AE）/103%（TE）；SwissCrop25 OA 保留 100%（AE）/99%（TE）/104%（S2），作物类别 mIoU 保留 104%（AE）。
- **对比最强基线**：PFF-VM 在 PASTIS 上比 TensoRF(VM) 提升 23 个百分点（67%→90%），在 FTW 巴西上提升 20 个百分点（70%→90%）。
- **续习实验**：PFF-Append 添加 2025 年数据，达到联合预训练新年份重构分数的 92%，训练时间仅 2%，旧年份保留率 100%；FT-All/FT-Dec 会导致灾难性遗忘。
- **速度对比**：PFF 在 L4 GPU 上检索 100 万 AE 嵌入仅需 79.5s（首次），Earth Engine API 需约 1422s（17.9× 慢）；H100 峰值吞吐 970 万嵌入/秒。
- **消融**：多分辨率 hash-grid（iNGP 风格）共享不如因式分解体积，说明因子化是关键；bit-proportional 容量分配优于 uniform 分配但对低维产品不利。

## 相关工作脉络
- **TensoRF(VM)、K-Planes**：早期张量/平面因式分解神经场方法，本文将其引入 EO 多产品联合建模，并扩展至持续学习场景；与原有应用（动态场景、辐射场渲染）不同，本文针对时空各向异性和多模态异构产品设计。
- **Instant-NGP (iNGP)**：基于多分辨率 hash 编码的显式-隐式混合场，本文对比表明共享 hash 网格不如因式分解体积有效，揭示因子化结构对跨产品共享的重要性。
- **地理坐标编码器（SatCLIP、GeoCLIP、Tessellating the Earth）**：全局隐式表示，学习位置到嵌入的映射；本文定位差异在于 PFF 作为源数据的紧凑替代（可重建），而非仅用于下游先验。
- **Feature Field 蒸馏方法（DFF、N3F、LERF、F3RM、FeatureNeRF）**：将预训练图像特征蒸馏为可查询 3D 表示；本文扩展至多产品联合压缩，并支持持续加入新产品/时间。
- **Continual NeRF 方法（CLNeRF、CD-NGP）**：基于回放与参数隔离更新参数；本文方法无需回放，通过冻结 + 追加参数实现比特精确持久化。
- **TerraCodec**：针对单产品（多光谱/时序）的神经编解码器；本文强调多产品共享表示、持续学习能力与检索速度优势，压缩比不可直接对比。

## 局限性与未来方向
- 压缩比因产品组合与冗余嵌入而波动（如加入 Galileo 从 1800× 升至 2800×），难以与单产品编解码器直接对比。
- 固定存储预算下不支持可变率压缩，对下游任务的影响依赖具体场景（平滑可能去除高分辨率映射所需细节）。
- 跨产品监督带来的去噪增益与互补监督效应的贡献尚未隔离验证。
- 连续删除时间切片会破坏比特精确性（插值锚点改变），仅支持追加。
- 未来方向可包括：探索动态容量分配、支持删除/编辑的持续表示、扩展到更多产品（如气候/生态变量）、与地球引擎等云平台集成。

## 研究启发与可借鉴点
- **共享因式分解体积 + 产品特定解码器架构**：可有效共享跨模态/跨分辨率数据的冗余结构，适用于任何多源遥感或时序信号压缩任务。
- **比特精确持续学习策略**：追加时间切片/解码器并冻结历史参数的设计，避免了灾难性遗忘，可迁移至其他需要持续更新的全局表示学习（如气候场、医学影像库）。
- **各向异性分辨率设计**：针对 EO 数据"空间密集、时间稀疏"特性独立设置空间与时间因子网格大小，这一原则可扩展至其他时空异质性数据集。
- **固定容量 GPU 缓冲区 + 部分 COG 读取**：解决 PB 级数据无法全量加载的问题，可通过 shuffle 与无放回遍历实现高效数据流，适合大规模遥感训练。
- **线性探针 + 充分统计量闭式求解**：在 SwissCrop25 实验中用 class counts、feature sums、second moments 替代迭代优化，显著降低计算成本，适用于大规模线性分类评估。

## 关键术语表
- **Planetary Feature Fields (PFFs)**：一种空间局部显式-隐式混合神经网络场，通过共享因式分解特征体积联合表示多源地球观测产品。
- **Factored Feature Volume**：将稠密时空特征网格分解为小维度因子（线性/平面），通过插值组合得到共享特征向量，降低存储与计算开销。
- **TensoRF(VM)**：基于矢量-矩阵分解的张量因式方法，将 3D 特征表示为线性因子与平面因子的加权和。
- **K-Planes**：基于三个方向平面因子逐元素相乘的显式神经场表示，支持多分辨率扩展。
- **Cosine Distortion**：1 - cos(ŷ, y)，用于单位归一化嵌入的重构损失，衡量预测与真实方向偏差。
- **Retention (%)**：下游任务使用重构特征得分与原始特征得分之比，100% 表示完全保留，>100% 表示超原始性能。
- **Continual Learning (PFF-Append)**：在冻结现有参数的基础上追加时间切片或产品解码器，实现无遗忘的增量更新。
- **Cloud-Optimized GeoTIFF (COG)**：支持范围读取的 GeoTIFF 变体，允许仅加载所需空间块以降低 I/O 开销。
