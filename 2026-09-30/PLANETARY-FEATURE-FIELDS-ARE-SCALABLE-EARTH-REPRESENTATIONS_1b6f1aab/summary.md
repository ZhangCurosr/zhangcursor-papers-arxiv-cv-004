# 论文速读：PLANETARY FEATURE FIELDS ARE SCALABLE EARTH REPRESENTATIONS

## 一句话总结
提出了行星特征场（PFFs），将多源地球观测数据建模为空间-时间连续函数，通过共享因式分解的特征体实现约1800×压缩比下的高保真重建，并支持仅需极小参数增量即可向新时间步和新产品持续扩展。

## 研究问题与动机
- 卫星观测（原始影像）、预计算嵌入（AlphaEarth、TESSERA）和地图产品（DEM、冠层高、水资源等）描述同一地球的演化状态，却各自作为独立的PB级数据产品存储、更新和维护，缺乏紧凑的共享表示。
- 现有"预训练模型在线提取特征"方案在全球尺度应用时需大量计算并依赖完整数据档案；"地理位置编码器"提供紧凑隐式表示，但只能捕获粗粒度地理结构，无法保留重建源数据所需的细粒度细节。
- "预计算嵌入"将计算移至离线阶段，但随时间增长，每个时间步都需另存一份全球数组，存储/传输/版本管理成本近似线性增长。
- 理想地球表示必须同时满足：（i）在全球尺度保留精细的时空细节；（ii）紧凑且支持快速检索；（iii）可向新时间步和新产品高效扩展而不破坏已有表示。

## 核心贡献（创新点）
1. **提出行星特征场（PFFs）——空间局部的显式-隐式混合神经场**。用共享的因式分解特征体编码跨产品的时空结构，配合轻量产品专属MLP解码器，在约1800×压缩比下实现高保真重建；与单产品基线相比，平均归一化失真降低约20%。
2. **证明PFF重建特征可保留约90%以上下游任务性能**。在像素级分割（PASTIS、SwissCrop25）、变化检测（EuroMineNet）和patch级分类（BigEarthNet-v2、So2Sat）上，与匹配压缩率的单产品神经场相比，mIoU/OA/AUPRC等指标提升18–44个百分点；部分任务甚至超越原始特征。
3. **实现无遗忘的持续学习机制**。新增时间步仅需追加约0.19–0.22%的新参数（时间切片），以2%训练时间达到联合预训练92%的新年重建分，同时旧年输出保持比特精确；新增产品只需训练一个约2%参数的新解码器，冻结共享场与旧解码器即可，所有已有输出不受影响。
4. **大幅降低端到端特征访问延迟**。在相同硬件（8 vCPU + NVIDIA L4 GPU）上，PFF materialize AlphaEarth嵌入比Google Earth Engine API快17.9×，比全图块下载快15.5×；在H100 GPU上实现9.7M嵌入/秒吞吐量。

## 方法详解
- **区域划分与坐标变换**：将地理域划分为局部区域（tile），每区域单独学习一个神经场；每个tile的空间范围缩放至 $[0,1]^2$，所有区域使用相同的相对坐标，避免全局坐标编码。
- **共享因式分解特征体（Explicit Factored Feature Volume）**：不存完整的 $N_x \times N_y \times N_t \times d_h$ 稠密网格，而是将其分解为若干低秩因子。支持两种构造：
  - **TensoRF(VM)分解**：每个方向有一组向量-平面因子对 $(v_r^a, M_r^{bc})$ 及基向量 $\mathbf{b}_r^a$，查询时沿各轴插值后加权和：$\mathbf{h}(x,y,t)=\sum_r v_r^x(x)M_r^{yt}(y,t)\mathbf{b}_r^x+\cdots$
  - **K-Planes分解**：存储向量值平面因子 $\mathbf{P}^{xy},\mathbf{P}^{xt},\mathbf{P}^{yt}$，通过逐元素乘法组合：$\mathbf{h}=\mathbf{P}^{xy}(x,y)\odot\mathbf{P}^{xt}(x,t)\odot\mathbf{P}^{yt}(y,t)$；K-Planes进一步引入4个空间尺度（147/294/588/1176）。
- **产品专属隐式解码器**：每个产品 $m$ 对应一个轻量MLP解码器 $g_m$，将共享特征 $\mathbf{h}(\mathbf{x},t)\in\mathbb{R}^{d_h}$ 映射至该产品原生特征空间：$\hat{\mathbf{y}}_m(\mathbf{x},t)=g_m(\mathbf{h}(\mathbf{x},t))$。
- **异构数据兼容**：不同产品在分辨率、维度、时间覆盖上存在差异；粗分辨率产品通过最近邻重采样统一到10m网格；缺失时间步/空间区域/通道均通过mask处理，训练时不要求全同步观测。
- **损失函数**：欧氏值产品（如Sentinel-2、DEM）用逐通道标准化MSE；单位归一化嵌入（如AlphaEarth）用余弦畸变 $1-\cos(\hat{\mathbf{y}}_m,\mathbf{y}_m)$；各产品loss等权相加。
- **训练缓冲区**：维护固定容量GPU buffer，随机选取空间块-年份对，通过部分COG读取加载，保证内存占用有界。
- **超参**：VM配置 $S=955$、$R_{x/y/t}=65$、$d_h=64$；K-Planes $d_h=128$；解码器为2层ReLU MLP（嵌入产品宽1024，其余宽256）；Adam优化（$\beta_1=0.9, \beta_2=0.99$）；训练20000次迭代，bf16混合精度。

## 实验与结果
- **数据集**：14种地球观测产品（5种原始观测、2种预计算嵌入、7种地图产品），时间跨度2017–2025（9年）；评估基准为100个PFFBENCH图块（共约67亿空间位置、16TB源数据）；下游任务包括PASTIS、SwissCrop25、FTW、EuroMineNet、BigEarthNet-v2、So2Sat-LCZ42。
- **重建质量**：在匹配压缩率下，PFF（VM和K-Planes两种）的mean reconstruction score分别达90.5和91.1，优于单产品TensoRF(VM)（88.8）、单产品K-Planes（88.9）和iNGP；对各类产品均有稳定提升。
- **下游任务保留率**（占原始特征性能的百分比）：
  - PASTIS语义分割：PFF-VM 达90%（AE）、90%（TE）、136%（S2）；PFF-K-Planes 达89%（AE）、87%（TE）、121%（S2）。
  - FTW巴西field instance召回：PFF-VM 90%/90%；PFF-K-Planes 95%/103%（优于原始S2的21.2）。
  - EuroMineNet变化检测（AUPRC/F1@r）：PFF-VM 100%/97%（AE）；103%/97%（TE）。
  - SwissCrop25作物分割：OA达100%/99%/104%；crop mIoU达104%/92%/111%。
  - Patch分类（BEN-v2、So2Sat）：各方法基本饱和，PFF略优。
- **持续学习**：新增2025年时间步（追加0.19%参数）：PFF-Append在2%训练时间内达到92%联合预训练得分，同时旧年R²保持100%；对整个PFF做finetune会导致旧年性能崩塌（灾难性遗忘）。新增Galileo嵌入（2%参数新解码器）：mIoU 42.2% vs 原始42.1%，同时完全保留AE和TE下游性能。
- **检索速度**：L4 GPU上1M AE embeddings比Earth Engine快17.9×（79.5s vs ~1424s），比完整COG下载快15.5×（TE）；H100 GPU峰值吞吐9.7M embeddings/s。

## 相关工作脉络
- **NeRF/神经隐式场**（Mildenhall et al., 2020；Instant-NGP；K-Planes；TensoRF）：PFF借鉴了因式分解特征体的紧凑表示思想，但将其应用于多产品、跨模态的地球观测数据，而非单一场景重建。
- **特征场蒸馏**（DFF、N3F、LERF、FeatureNeRF）：此类方法将预训练图像特征蒸馏为可查询的3D表示；PFF与之不同——PFF直接以原始观测和嵌入为监督信号训练，而非对预训练特征进行蒸馏。
- **大规模场景神经场**（Block-NeRF、KiloNeRF、Mega-NeRF）：这些方法通过场景分块加速渲染；PFF也采用空间分块策略，但核心贡献在于共享因式分解特征体实现多产品联合压缩。
- **地理位置编码器**（SatCLIP、GeoCLIP、Tessellating the Earth）：全局隐式表示擅长粗粒度地理先验，但重建精度不足；PFF以局部显式场弥补这一缺陷，同时兼具紧凑性与高保真。
- **持续学习神经场**（CLNeRF、CD-NGP）：通过重放或参数隔离机制更新场景；PFF的方案更简洁——直接冻结旧参数、仅扩展新时间切片或新解码器，实现比特精确的向后兼容。
- **数据压缩编码**（TerraCodec）：面向单产品类型做有损压缩；PFF面向多产品共享表示，压缩比定义不同，且支持持续增量更新。

## 局限性与未来方向
- 压缩比的计算受产品组合和缺失情况影响较大（如加入Galileo使压缩比从1800×升至2800×），不同研究间直接比较困难。
- 每个PFF在固定存储预算下训练，不支持变率压缩（variable-rate compression），难以在低预算下精细调节保真度。
- 重建是有损的，平滑效应可能去除高分辨率映射所需的细粒度结构（虽然有时也起到轻微去噪效果，实验未分离此影响）。
- 未来方向：探索变量率压缩、向更多产品和时间步扩展、将PFF应用于更大规模地球系统建模任务。

## 研究启发与可借鉴点
1. **因式分解特征体用于跨模态共享表示**：将时空特征分解为低秩因子（VM或K-Planes），可同时适配EO数据"空间密集、时间稀疏"的各向异性特性，该设计可直接迁移至多模态时序数据的紧凑表示学习。
2. **持续学习中的"冻结+扩展"范式**：新增时间步仅扩展新切片、新增产品仅训练新解码器，保证旧输出比特精确不变；这一思路适用于任何需要增量扩展的神经表示系统，无需灾难性重训练。
3. **共享表征带来的隐式正则与互补监督**：多产品联合训练使得共享特征体受到多种互补信号的约束，重建结果偶尔超越原始特征（如S2在PASTIS上达136%），提示跨模态共享表征本身具有去噪和增强效应。
4. **局部神经场+全局路由的工程架构**：将全球域划分为独立区域字段，通过坐标映射路由查询，兼顾了表示容量与推理效率，可推广至全球尺度的遥感大模型服务部署。
5. **以端到端任务保留率为评估标准**：用下游任务（分割、变化检测、分类）的性能保留率而非单纯PSNR/SSIM来衡量表示质量，对地球观测AI更具实际指导意义。

## 关键术语表
**Planetary Feature Fields (PFFs)**：一种空间局部的显式-隐式混合神经场，通过共享因式分解特征体将多源地球观测数据编码为时空连续函数。
**Factored Feature Volume**：将稠密时空特征网格分解为若干低秩因子（向量+平面）的紧凑表示结构，典型实现为TensoRF(VM)和K-Planes。
**TensoRF(VM)**：因子化神经场的实现方式之一，通过沿各轴的向量-平面对和基向量的加权和构造共享特征。
**K-Planes**：因子化神经场的另一种实现，使用向量值平面因子并通过逐元素乘法（Hadamard积）组合。
**Continual Learning (无遗忘)**：在不重新训练已有参数的情况下，向现有模型追加新时间步或新产品，保持旧输出比特精确。
**AlphaEarth (AE) / TESSERA (TE)**：两种预计算的全球地球嵌入产品，分别从64维和128维向量空间表征地球表面，单位为int8。
**PFFBENCH**：论文构建的1000个全球图块基准数据集，用于评估PFF重建质量和下游任务性能。
**Angular Skill**：针对单位归一化嵌入的评估指标，衡量余弦畸变相对于均值方向预测器的改善程度。
